🔐 Flujo de Autenticación Unificado
Mismo flujo para app móvil y panel administrativo web
1

🙋 Inicio de sesión del usuario

El usuario ingresa credenciales (email o teléfono + contraseña) desde la app móvil o panel web

↓
2

🔥 Firebase Authentication

Firebase valida las credenciales y genera un ID Token (JWT) firmado

↓
3

📤 Envío del token al backend

El cliente envía el token en cada request:
Authorization: Bearer <token>

↓
4

⚙️ Validación en Django DRF

El backend verifica el token con firebase-admin SDK de forma server-side

↓
5

🗄️ Asociación con PostgreSQL

Una vez validado, el token se asocia con el perfil del usuario en la base de datos

✅ Sistema de autenticación unificado, seguro y reutilizable para ambas plataformas
